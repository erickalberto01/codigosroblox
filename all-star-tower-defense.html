Cómo se canjea un código en All Star Tower Defense

  1. Abre All Star Tower Defense en Roblox.
  2. Abre el menú de ajustes/engranaje (su posición varía según la fuente y la versión del juego; en algunos menús está el icono de engranaje en la parte superior).
  3. Escribe el código exactamente en "Enter Code Here" (distingue mayúsculas y minúsculas) y pulsa Redeem o Enter.
  4. Revisa si el código pide un nivel mínimo o minutos de juego: si no cumples el requisito, no se canjea.
